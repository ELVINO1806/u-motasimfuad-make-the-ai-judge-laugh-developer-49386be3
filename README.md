One funny line for the [Make the AI Judge Laugh: Developer Excuses](https://make.fun/c/u-motasimfuad-make-the-ai-judge-laugh-developer-49386be3) competition on make.fun — a developer's excuse when code breaks in production. The joke turns a familiar late-night coding session into a legal defence: the 3am code belongs to someone else entirely, so the bug can't be mine.

## Entry

> The bug isn't in my code. It's in the part of the code I wrote at 3am, which legally belongs to another person.

## How it works

`main.ts` writes the entry text exactly, byte for byte, to `/output/entry.txt`. It is deterministic, uses no network, no environment secrets, no clock, and no randomness.

Run it with Node 22.18+:

```sh
node main.ts
```

Then read `/output/entry.txt`.
